圖片壓縮工具 — 使用說明
==============================

【系統需求】
  Windows 10（1809 以後）或 Windows 11，64 位元。
  不需要安裝 Python 或任何套件，所有需要的東西都在這個資料夾裡。

【安裝】
  1. 把 zip「全部解壓縮」到任何資料夾（例如 D:\Tools\CompressPicture）。
     ※ 不要直接在 zip 裡面雙擊執行，會因為找不到 _internal 資料夾而無法啟動。
  2. 雙擊 CompressPicture.exe。
  3. 第一次執行如果出現「Windows 已保護您的電腦」（SmartScreen）：
     按「其他資訊」→「仍要執行」。這是因為程式沒有數位簽章，不是病毒。

  要移除：直接刪除整個資料夾即可。
  （程式設定存在登錄檔 HKEY_CURRENT_USER\Software\CompressPicture，不刪也沒關係。）

【使用】
  1. 把圖片或資料夾拖進視窗（支援 PNG、JPG、WebP，資料夾會包含子資料夾）。
  2. 右邊選擇「無損壓縮」或「有損壓縮」，以及輸出位置。
  3. 按「開始壓縮」。完成後雙擊檔案可以比較壓縮前後。

  無損壓縮：畫質完全不變，每張都會逐像素驗證。
  有損壓縮：檔案小很多，畫質有些微差異。
  預設「另存新檔」（檔名加 _min），不會動到原檔。

【如果無法執行或結果怪怪的】
  雙擊資料夾裡的 selftest.bat：會在背景測試所有壓縮功能（約 10 秒），
  顯示 OK 代表一切正常；顯示 FAILED 時，請把同一個資料夾裡產生的
  selftest.json 交給維護者。
